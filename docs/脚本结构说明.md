# 脚本结构说明

## 段落拆解

```
┌─────────────────────────────────────────────┐
│  开场 3秒   各位老板，今天刷到一个消息——[热点] │
│             ↓ 制造信息差，让老板想继续看       │
├─────────────────────────────────────────────┤
│  痛点 5秒   [具体场景的痛点描述]               │
│             ↓ 让他觉得"说的就是我"             │
├─────────────────────────────────────────────┤
│  方案 8秒   其实解决这个问题很简单……           │
│             ↓ 给出解法，不推销，只提供          │
├─────────────────────────────────────────────┤
│  价值 6秒   现在29省200+城市1000家门店都在用     │
│             ↓ 用数字建立信任                   │
├─────────────────────────────────────────────┤
│  CTA 3秒    想了解的评论区扣"百应"，我私信你     │
│             ↓ 低门槛，把动作降到最低            │
└─────────────────────────────────────────────┘
```

## 写作铁律

### 1. 开场必须点名热点
❌ "今天跟各位老板聊点生意上的事"
✅ "今天刷到一个消息——全球手机销量暴跌"

### 2. 禁用"加盟"
❌ "想加盟联想百应的私信我"
✅ "想加入百应的私信我"

### 3. 痛点要具体到画面
❌ "现在生意越来越难做"
✅ "以前一天接十几个单，现在一天就两三个"

### 4. 数字用官方口径
- 29省
- 200+城市
- 1000家门店
- 3年

### 5. 不承诺做不到的
❌ "月入十万"
✅ "月流水提升看得见"

---

## 为什么这样设计

| 设计点 | 原因 |
|--------|------|
| 开场3秒点名热点 | 蹭的是平台流量，不是你账号的流量 |
| 痛点先于方案 | 先建立同频，再给解法，否则像广告 |
| 方案用"帮"不用"让" | 降低推销感 |
| 价值用数字 | 老板只信数字和案例 |
| CTA是"扣字"不是"留电话" | 门槛越低，行动越多 |
| 结尾停住 | 给字幕和评论留时间 |

---

## 不同平台调整

| 平台 | 调整 |
|------|------|
| 抖音 | 前3秒必须够炸，可以加"别划走" |
| 视频号 | 老板年龄偏大，语速放慢，字幕加大 |
| 两个都发 | 同一脚本，抖音版加钩子，视频号版加解释 |
