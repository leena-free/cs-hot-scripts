# 使用指南 · CS城市经理

## 一、拿到最新脚本（3种方式）

### 方式1：GitHub 网页（最简单）
1. 打开 https://github.com/leena-free/cs-hot-scripts
2. 点 `daily/` 目录
3. 找今天日期的 `.html` 文件
4. 点 Raw 或直接下载，用浏览器打开
5. 点每条脚本右边的「复制脚本」按钮

### 方式2：git clone（推荐，会自动更新）
```bash
git clone https://github.com/leena-free/cs-hot-scripts.git
cd cs-hot-scripts

# 以后每天更新
git pull
```

### 方式3：直接问工仔
飞书里说一句"今天的CS脚本"，我直接发你。

## 二、怎么用一条脚本

1. **选一条** — 挑跟你今天想说的最接近的热点
2. **录** — 用手机横屏或竖屏对着自己，第一句必须点出热点事件
3. **发** — 发到抖音 + 视频号（双平台矩阵，别只发一个）
4. **回线索** — 评论区有人扣"百应"，截图发我，我来跟进

## 三、拍摄提示

| 项目 | 建议 |
|------|------|
| 时长 | 30秒左右，别超40秒 |
| 语速 | 稍快一点，1.25倍速最自然 |
| 字幕 | 必须加，老板们多在静音下刷 |
| 首帧 | 一定要有文字标题（"手机销量暴跌"这类） |
| 结尾 | 停在"评论区扣百应"这句话上 |
| 发送时间 | 早8点前 或 晚7-9点（老板们起早/收工后刷） |

## 四、常见问题

**Q：脚本里的数字对不对？**
A：脚本里只用了"29省/200+城市/1000家门店"这三个官方口径数字，不会错。热点部分的数字都经过百度验证。

**Q：可以把脚本改成自己城市的名字吗？**
A：可以，改具体地名和门店名效果更好。比如"我在东莞开了5年修电脑店"。

**Q：同一个热点别人也拍怎么办？**
A：脚本给了4条，角度不同（手机销量/AI/创业/新品），选跟自己客户最相关的那个。

**Q：评论区没人扣"百应"？**
A：前3秒没抓住人。换个开头试试，或者在结尾加一句"我私信你一份免费的报价表"。
