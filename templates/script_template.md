# 脚本生成规则

> 生成脚本时必须遵守以下规则，不可套用固定模板内容。

## 一、脚本结构（段落固定，内容动态）

```
【开场3秒】→ 必须点名今日热点事件
"各位老板，今天刷到一个消息——[热点事件]"

【痛点5秒】→ 引出门店老板共鸣，落到日常经营场景
"[与热点相关的痛点描述]"

【方案8秒】→ 自然植入百应解决方案
"其实解决这个问题很简单……[百应如何帮助]"

【价值6秒】→ 具体数字信任背书
"现在[数字]都在用，效果[具体描述]"

【CTA3秒】→ 低门槛引导
"想了解的评论区扣'百应'，我私信你"
```

## 二、硬性规则

1. **开场必须点名热点** — 不能用"今天聊聊XX"这种空开场
2. **禁用词**：加盟 → 一律替换为「加入百应」
3. **痛点要具体** — 缺品牌/缺客户/缺备件这类真痛点，不能泛泛而谈"生意难做"
4. **数字要精准** — 29省/200+城市/1000家门店，不能模糊
5. **CTA要低门槛** — 评论区扣关键词 + 私信，不要求留电话
6. **口语化** — 读出来不卡壳，控制在300-400字（1-1.5分钟）

## 三、可用信息库

| 类别 | 内容 |
|------|------|
| 获客 | 美团 + 抖音全网获客 / 主动找到周边3公里内有需求的人 |
| 供给 | 运营商合作（移动/电信 IT+CT）/ 宽带、监控、门禁等大单 |
| 数字 | 29省 / 200+城市 / 1000家门店 |
| 效率 | AI 辅助工具 / 智能报价 / 库存管理 |
| 结果 | 月流水提升 |

## 四、选题方向（热点匹配优先级）

1. 📱 **3C/数码** — 新品发布、销量数据、维修需求变化
2. 🤖 **AI/科技** — AI 在门店场景的应用
3. 💼 **就业/创业** — 副业、开店、自雇趋势
4. 📡 **运营商** — 宽带、监控、智能设备
5. 💰 **消费/省钱** — 消费降级、性价比、换机周期变长

## 五、输出格式

- 每日一个 Markdown 文件（归档用）
- 每日一个 HTML 文件（CS 直接复制用，含复制按钮）
- 每个脚本标注：热点标签 + 角度说明
